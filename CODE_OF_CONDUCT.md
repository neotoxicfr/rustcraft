# Code of Conduct

Rustcraft follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be respectful and kind to everyone, whatever their level, background, gender or identity.
- Criticise the code and the ideas, never the people.
- No harassment, insults, discriminatory remarks or publication of other people's private
  information.

Unacceptable behaviour can be reported privately to the repository maintainers. The maintainers can
remove content, and temporarily or permanently exclude a person from the project.
