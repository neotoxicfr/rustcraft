# Quirks of the official game to reproduce

Rule (user request, 12/10/2026): Rustcraft reproduces the official 26.3 game **bugs
included**. A behaviour that is absurd but present in the game (often exploited by technical
players) is reproduced as is; a bug **fixed** in the target version is never
reintroduced. The judge is the 26.3 code and the comparison with the official server (same setup,
same result, tick by tick), never a list found on the internet: the ones that circulate are
often old, contradictory or wrong. The cases below are **leads to verify**
in every mission that touches the domain; the status is noted here.
